# TriconX Technology Website

A zero-cost, self-contained static website for TriconX Technology.

## Run locally
Double-click `index.html` or open it in any modern browser.

## Publish for free with GitHub Pages
1. Create a GitHub account.
2. Create a new public repository.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. Open Settings → Pages.
5. Choose "Deploy from a branch", select `main` and `/root`.
6. Save.
7. GitHub will provide a free `github.io` website address.

## Customize
- Replace text in `index.html`.
- Replace `assets/triconx-logo.png` if you create a new logo.
- Change colors and layout in `style.css`.
- Change interactions in `script.js`.

Note: the contact email is a placeholder. Replace `hello@triconxtechnology.com` with your real contact address before publishing.
